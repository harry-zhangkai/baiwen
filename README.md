# 百问

网页模型聚合桌面 AI 客户端（内测版）。

> 本仓库仅用于发布安装包，不含源代码。

## 下载安装

### macOS（Apple Silicon / Intel 通用）

终端粘贴执行一条命令即可：自动识别芯片架构、下载最新版、关闭运行中的百问后覆盖安装到「应用程序」，完成后自动打开（命令行下载的安装包不带隔离标记，装好直接能开）：

```bash
curl -fsSL https://raw.githubusercontent.com/harry-zhangkai/baiwen/main/install.sh | bash
```

若提示「百问无法自动退出」，请手动退出百问（右键 Dock 图标 → 退出）后重新执行。

### Windows x64

下载安装程序：[baiwen-0.1.0-win-x64-setup.exe](https://github.com/harry-zhangkai/baiwen/releases/download/v0.1.0/baiwen-0.1.0-win-x64-setup.exe)

双击运行，按提示选择安装目录，完成安装。
